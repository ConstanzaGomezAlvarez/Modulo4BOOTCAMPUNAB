Reglas del set
Un jugador gana el set si:

Tiene 6 juegos ganados y el otro tiene menos de 5

Tiene 7 juegos ganados y el otro tiene 5 o 6

El set está todavía en juego si:

Ambos jugadores tienen menos de 6 juegos, o

El marcador está empatado en 6–6 (podría ir a tie-break)

El resultado es inválido si:

Alguno tiene más de 7 juegos

Hay puntuaciones como 8–6, 7–3, etc. que no ocurren en reglas estándar
